# Security

Please don't report security problems in public issues. Write to x@alpwrk.cc instead, with what you found and how to reproduce it.

You'll get an answer within a few days. Once a fix is out, the problem can be made public, and you'll be credited if you want to be.

Only the latest release gets fixes.

Rhein is alpha software, and its cryptography (OPAQUE login, MLS, call encryption) has not been audited.
